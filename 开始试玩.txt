# Dustline 0.6.6 试玩说明

Mac 运行 `Tools/play.command` 或打开 `Builds/macOS-0.6.5/Dustline.app`。
Windows 解压整个压缩包，双击 `Dustline.exe`；请保留同目录的数据和运行库。

## 开始游戏

单人爆破无需联网。在主菜单选择进攻方 T 或防守方 CT，再点击开始；Enter 使用当前阵营开始。双方共 10 人，空位由 BOT 补齐。

好友联机可创建本地房间，或手动输入房主提供的服务器地址、端口和房间口令加入。游戏包不预设服务器地址或口令，也不会自动连接测试服。默认端口为 `27015 / UDP`，可在联机界面修改。0.6.6 使用协议 v11，联机双方与房间服务器都需要同版，不能与 0.6.5 或更早版本混用。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 静步 / 蹲伏 | WASD / Shift / Ctrl 或 C |
| 跳跃 / 换弹 | Space / R |
| 开火 / 瞄准或特殊模式 | 鼠标左键 / 右键 |
| 主武器 / 手枪 | 1 / 2 |
| 检视武器 | F |
| 快速切回上一件装备 / 循环切换装备 | Q / 鼠标滚轮 |
| 刀与 Zeus / 切换投掷物 / C4 | 3 / 4 / 5 |
| 高爆 / 闪光 / 烟雾 / 诱饵 / 燃烧道具 | 6 / 7 / 8 / 9 / 0 |
| 丢弃 / 拾取或使用 | G / E |
| 购买 / 记分板 | B / Tab |
| 暂停菜单 / 切换窗口和全屏 | Esc / Alt + Enter |

持刀时左键挥砍，右键重刺。持投掷物时按住左键、双键或右键选择三档力度，松开投掷。安包时用 5 选择 C4，等待拔出后在包点站定并按住左键；松键、移动、切枪或离地会中断。拆包按住 E，携带或手持 C4 进入包点仍可用 E 拾枪。

G 丢出的枪会保留移动惯性并抛落，可以在空中接住。阵亡时优先掉落主武器，没有主武器才掉落手枪；枪中的余弹仍保留。

右键功能随枪械变化：狙击镜或瞄准镜、Glock / FAMAS 连发切换、USP-S / M4A1-S 消音器拆装、R8 快速射击。霰弹枪逐发装填时可以开火中断。弹匣枪换弹到装好弹药的动作后，切枪会保留已经装入的子弹；动画后半未结束时仍不能直接射击。

F 播放当前武器的原版检视动作，可在键位中改绑；开火、换弹、切枪和开镜会中断检视。换弹期间不能开镜，鼠标使用普通灵敏度；AWP 射后拉栓时暂时退镜，默认在拉栓结束后恢复原来的开镜档位；可在“武器”设置关闭自动开镜，之后用右键手动开镜。已就绪的 AWP 可以同时按下开镜与开火，无须等待镜头动画。

每回合出生会补满仍持有枪械的弹匣和备弹；投掷物不会凭空补发。回合结束后的 7 秒可以继续移动、跳跃、换弹和射击，到下一回合准备时才冻结。比分两侧显示双方各五个头像，阵亡头像变灰；击杀记录在右上角显示。

人物阵亡后从最后的骨骼姿势进入物理倒地，使用原模型的碰撞身体与关节约束，并与附近地图碰撞。本人的视角短暂停留后过渡到存活队友；没有存活队友时保留自身死亡视角，下一回合恢复正常。Unity 与 Source 的物理解算不同，倒地轨迹并非逐帧一致。

静步和蹲走有不同的速度与起步／刹停过程，地面蹲下和站起有连续过渡。跳起后蹲下可以收腿越过更高的障碍；持续按住跳跃不会自动连跳。队友和敌人都会挡路，人物顶部可作为落脚点配合越障。

## 游戏设置

主菜单或 Esc 菜单可打开游戏设置，点击“应用并保存”后跨启动保留。

- 画面与显示：窗口、无边框全屏、Windows 独占全屏；自动、4:3、16:9、16:10、21:9 比例及对应分辨率；保持比例黑边或拉伸填满；流畅、均衡、精细三档画质；亮度、垂直同步、帧率上限和帧率显示。
- 声音：主音量、枪声／脚步／动作音量、回合／炸弹提示和菜单音乐；可试听枪声。
- 鼠标：普通灵敏度、开镜倍率和垂直方向反转。
- 武器：狙击射后自动开镜、持枪视角 FOV、左右／前后／上下偏移和左手持枪；提供桌面、沙发、经典预设。
- 键位：29 个常用操作，每项支持主键与备选键，可绑定键盘、鼠标按钮／侧键和滚轮；提供冲突提示、清空和恢复默认。
- 准星：长度、间距、粗细、透明度、RGB 颜色、中心点、描边、T 形和动态扩散，提供实时预览。

亮度在设置页实时预览；显示模式和分辨率在应用后切换。未保存就返回会撤销预览。恢复默认后还需点击应用并保存。

想使用经典 4:3 拉伸画面，可选择“4:3”和“拉伸填满”，再选择分辨率并应用。希望保留正常比例则选择黑边模式。默认画质为“均衡”；帧率不足时可切换“流畅”，其内部渲染精度和阴影开销更低。

单机打开菜单会暂停比赛和投掷物效果；联机时比赛继续运行。离线暂停菜单内 R 可重新训练，M 返回主菜单。

## 滚轮跳与自定义键位

进入“游戏设置 → 键位 → 移动”，将“滚轮跳”改为“滚轮向下”“滚轮向上”或“滚轮双向”，再点击“应用并保存”。开启后，原跳跃主键和备选键继续有效，默认空格仍然可以跳；所选滚轮方向只触发跳跃，不再切枪。关闭滚轮跳后，该方向恢复原键位功能。

在“键位”页选择分类，点击主键位或备选键位，再按下新键。Esc 取消本次修改，Backspace 清空当前格。冲突时可重新选择或明确替换；替换会清空另一操作对该键的绑定。返回而不保存会放弃修改。恢复默认键位只重置键位和滚轮跳，不影响画面、声音与灵敏度。Esc 始终可返回菜单，Alt + Enter 保留窗口／全屏切换。

Q 在最近两件仍持有的装备之间切换；包括刀、投掷物和携带中的 C4。掉落或已消耗的装备不会被重新选中。6～0 是投掷物快捷键，只有持有对应道具时才生效。

## 本版内容与边界

原版 Dust2、43 件经典竞技装备、23 款 legacy 刀具及原版人物、持枪模型、动画和音频已接入。枪械脚本数值与动画时长来自同一 CS:GO legacy 版本（build 12426195）。黄金刀在原资源中没有独立检视动作，部分刀具共用原版攻击音效。

0.6.1 修复自动武器连续射击时后坐力异常堆积，以及 A 大、T 出生点和部分地形／物件接缝卡脚；沿用原始地图可见性数据减少无须绘制的部分，并接入原版 3D 天空几何的独立视角和雾参数。

0.6.5 继续校准各枪后坐力和投掷方式，修复购买成功提示黑框、弹痕与短暂曳光，并补齐第三人称移动瞄准姿态；HP／弹药背景透明，强闪先完全遮白再逐渐恢复，烟雾会展开和消散，诱饵响枪有间隔并会结束，火焰沿可见地面展开。子弹使用原版地图表面材质与实际厚度计算穿透和伤害衰减，穿过人物后仍需判断后方墙体。

0.6.6 修复观战时的持枪与换弹显示；拆分原版瞄准后坐力与额外镜头冲量。狙击镜随移动精度变化而模糊，射击与换弹后按 0.1 秒过渡恢复原镜级，打空弹匣时不自动复镜。地图雷达与颜色查找表改为同版原文件，枪口效果按武器、第一／第三人称及消音器状态选择原粒子图。原地图的复杂死亡碰撞体会在加载时准备，减少对局内临时生成。

新增原版第三人称射击动作、身体／防弹衣／爆头／头盔不同命中声、匕首挥空与命中声音。自己命中头部时始终播放确认声；其他玩家听到的命中声继续按距离衰减。友军命中保留接触特效和声音，但不扣生命或护甲。采用原始音频并不代表已经复现全部原版空间声学。

Windows 默认优先使用 Direct3D 11，这是在 RTX 3060 Laptop 对等场景实测后选用的路径，Direct3D 12 仍保留可用。首次进入菜单前会准备常用模型、声音、实际渲染与比赛逻辑，期间请等待加载完成。新配置默认帧率上限为 400；已有玩家的上限会保留，可在“游戏设置 → 画面与显示”调高并检查垂直同步。准备工作不能保证所有硬件或所有场景都无慢帧。

这是持续开发的 Unity 可玩版本。人物命中范围已采用原模型的胶囊和旋转盒，按持枪类别、蹲伏和瞄准方向定位；服务端与显示端现在使用共享的原模型动作采样，包含跑跳、蹲伏、瞄准、开火与换弹。投掷物呈现、动作混合、弹道随机种子和穿透追踪仍需进一步与原程序对照，不能视作 100% 原版复刻。构建、真机运行和网页发布结果需分别验证，详见本版验收记录及 `PARITY_AUDIT_0.6.6.md`。


个人仓库：主菜单选择“个人仓库”，为 CT / T 分别装备刀具，共 23 款 legacy 刀具。F 检视（原黄金刀没有独立检视动作），左键挥砍、右键重刺。

购买：B 打开六类装备轮盘，数字键或鼠标选择，右键 / Esc 返回上一级，B 关闭。本回合购入且未使用的装备可在购买时间和购买区内通过右侧退款按钮退还；使用、丢弃或受到影响的防护装备不可退。退款是本游戏按需求增加的功能。
